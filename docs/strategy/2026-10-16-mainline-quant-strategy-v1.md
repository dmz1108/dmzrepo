# 确认主线龙头短持：量化研究与模拟规则 v1

状态：研究候选，未批准实盘；不是已经证实可盈利的产品。
Owner要求：研究一套可行的量化交易策略。

## 本轮判断

最适合先做完整验证的是“确认主线中的龙头短持”，不是直接将所有预期明星买入。
核心假设是：真实资金与确认明星证明方向正在被交易，历史辨识度较高的龙头可能存在短期延续。
这只是可检验假设。本轮已经将资金、数量、成本及部分无法卖出情形落实为离线工具，
发现7月的条件性组合模拟亏损，因此不能宣布找到了稳定盈利策略，也不能直接连账户。

“明星封板瞬间买入”仍是Owner既定的另一条研究路径。当前7/8月材料不足以验证首次确认后
是否买得到，不能把日线最高价或当日涨停价当成成交价。该路径暂不与本策略混做收益统计。

## 前瞻规则：先锁定，再模拟

以下数值是明确的初始研究/风险预算，不是从两个月搜索出来的最优参数。
修改任一条件都必须新版本登记，不能看完次日结果后修改旧信号。

### 1. 可交易信号

1. D日收盘后16:00北京时间固化候选、完整成员、龙头排名及证据版本；缺资料则当日不交易。
2. 必须是本源当日有效资金数据、正确家族归因、至少3只同族涨停，并有真实L2确认明星的主线。
   不因涨停最多就入选；东财/同花顺不把同股、同题材资金叠加；跨源同股只留一笔。
3. 明星沿用Owner规则：自己的最大可统计档完整，主动买入累计>1.5亿元或被动买入>2亿元；
   最大档主动比、50万档主动比、最大档合力比至少2项严格>2，并有当时封板证据。
   只有>1.65的预期明星不满足此门槛。
4. 从每条合格主线当时的前两名龙头选候选，不根据次日涨幅重算排名。新题材没有合格龙头则空仓，
   不把任意首板股硬叫龙头。现有评分不是已验证的收益预测器，后续必须独立验收。
5. 候选冲突用固定顺序：龙头名次升序、保存的评分降序、股票代码升序。历史工具使用规范输入
   保留下来的分数，不额外挑跨源最高分。前瞻必须记录评分来源与版本。
6. ST、北交所、上市初期无价格限制、停牌、未知公司行为或无交易权限的股票不发委托。
   这些时点状态在本轮历史代理池里未完全核验，不假装已经全部执行过该过滤。

### 2. 入场

- 只用前一晚已经固化的信息确定买入名单、股数和最高限价；最高限价=D日收盘价×1.03，向下取分。
- D+1开盘附近仅尝试一次限价买入；不追价、不因另一只没成交临时递补、不做亏损加仓。
- 模拟执行器应记录委托时间、盘口、排队/部分成交、撤单确认及撤单途中成交。
  不能假设开盘未成交的普通限价单自动消失。
- 本轮日线回放只是更粗的开盘集合竞价参考模型：开盘价不高于预设限价则假设全额成交，
  否则无成交；不能据此证明实际9:30附近价格/成交。前瞻模拟需以实时盘口回报替换这一假设。
- 价格高开超过限价就放弃，不为追求历史收益取消这个约束；开盘跳空下跌亦不事后删掉。

### 3. 仓位和现金

- 独立模拟账户10万元仅作测算单位，不代表Owner应投入的资金；无融资、无杠杆。
- 按下单时净资产：单股不超过20%，总股票名义暴露不超过60%，同族不超过40%，最多3只。
- 当前持仓加待发委托共同占用预算；同股不重复加仓，多族股票保守地向每族计足全额暴露。
- 股数在前一晚按限价和成本预算向下取整；主板/创业板100股单位，科创板至少200股、此后1股递增。
  实际权限以券商核验为准。资金不足一个最小单位则跳过，不用小数股假装成交。
- 不提前使用次日卖出所得，不假设同一开盘能先卖完再重新配置全部现金。
- 仓位上限是下单约束；持有期间价格变化会造成比例漂移，不承诺始终不超限。

### 4. 退出和停用

- 正常：D+1买入，D+2收盘附近执行时间退出；不因次日最高价漂亮而假设卖在最高价。
- 防守：若收盘相对买价跌幅达到6%，在下一个可卖日开盘提交卖出，而不是违反T+1当日卖出。
- 跌停/停牌/无买盘不能假设成交；继续占用持仓和风险预算，下一可执行时点重试。
  研究结束仍未卖掉则保留未平仓项目，不强制按某个好看的价格清仓。
- 收盘账户单日亏损达到2%，或从净值高点回撤达到6%，停止新增仓位；已有仓位按退出规则处置。
  不自动恢复，须核查行情、成交和策略有效性后由Owner决定。
- 这些不是亏损保证线。7月模拟已出现单日-3.319%，说明隔夜跳空可以直接穿过2%的停用预算。
- 本轮不加入盘中止盈、均线择时或更多阈值搜索，以免凭10个信号日拟合出漂亮曲线。

### 5. 数据故障是禁止交易，不是“今日无主线”

开新仓前必须确认：资金与成员sourceDay=D、字段非空；价格及交易状态有效；L2登录/任务成功、
证据同日且最大档齐全；归因可核验；信号availableAt不晚于固化时点；账户持仓/现金对账一致。
任何一项不可知则暂停相应开仓，保留failed/dataMissing，禁止伪造零或改作正常负样本。

前次10-16审计中，09-21至10-16的969个L2任务全部失败，950个为Login code -2。
这是已观察的阻断而非永久事实：恢复并复测之前不能启动依赖L2的前瞻策略。本轮没有修登录或换密钥。

## 条件性组合模拟结果

初始资金均10万元。正常摩擦假设每边10bp，另收假设全佣万3、每笔最低5元，
卖出印花税参数万5；全佣假设含常见经手费用，不另重复加收。并非Owner券商报价。
摩擦作为独立现金成本扣除，不伪装成违反限价的成交价。压力情景只提高摩擦，不反选规则。

| --- | ---: | ---: | ---: | ---: | ---: |
| 07-13~07-29 | 3 / 2 | -3.750% | -3.750% | -3.908% | -4.171% |
| 08-10~09-08 | 13 / 7 | +7.126% | -1.985% | +6.383% | +5.121% |

这不是7/8月完整月收益，更不是实盘。8月末信号的持有/退出延伸至9月，因此窗口如表所示。
“最大回撤”只按收盘净值标记，不是盘中风险上限。假设成交、候选完整性与时点真实性均未通过验收。

- 7月共有6个候选事件：2个参考开盘价超过限价，1个受持仓预算约束，最终3笔全部亏损。
  逐笔无约束均值为正，并没有自动转化为可执行账户收益。不能悄悄去掉限价或改挑赢家。
- 8月共有36个候选事件：20个因持仓数预算未发单，2个开盘超限，1个不足风险/整手预算，最终13笔。
  两笔最大盈利共6055.72元，占净利润7125.57元的84.99%，存在明显收益集中。
- 去掉一个信号日后，8月重复模拟净值变化范围+1.950%~+12.021%；7月-3.750%~-1.256%。
  这只是已观察样本的敏感性，不是样本外成绩或置信区间，不能从中挑一个最优删日版本。
- 两段的价格/现金机械检查没有未平仓、价格缺失或触发的公司行为告警；
  这只说明当前工具已覆盖的检查通过，不意味着完整公司行为、真实成交或旧信号时间已核验。
- 没有将条件性净值变化与满仓指数直接相减后宣称alpha。两者仓位、题材与风格暴露不同。

## 结论与推广门槛

结论：有一套能实现、能复算的研究规则，但跨样本稳定盈利尚未成立；只适合先做模拟。
不从这两个窗口再穷举均线、打分权重、止损或题材阈值来“修”出正收益。

前瞻验证建议锁定本版本，至少观察60个交易日、累计100笔已平仓及30个不同信号日，
三项都满足才进入正式复核；这些只是最低研究量，不是达到即盈利的保证。期间：

1. 记录全部候选、拒绝理由和故障日，原始时间戳和版本不可回写，不能只存最终上榜者。
2. 保存当时行情、委托、部分成交及撤单结果；大单和涨停股必须证明买得到，退出亦同。
3. 使用真实券商费用及实测滑点，按资金占用输出账户净值、盘中/收盘回撤、尾部损失和停用事件。
4. 成绩按信号日/时间块处理相关性，做成本压力和剔除最佳信号日对照，避免同题材多股当独立样本。
5. Owner与独立复核者须确认至少跨不同市场状态的净期望证据；置信区间仍跨零则继续观察，
   不按“胜率>50%”或某月漂亮收益直接批准。若改规则，版本重置，旧数据归训练/研究集。
6. 连接真实账户前核对适当性权限、历史交易状态、精确涨跌停价和券商程序化交易报告要求。
   本轮不申请权限、不报送、不下任何真实或模拟券商订单。
